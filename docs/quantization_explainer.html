What Kind of Quantization Is This?

EfficientQAT implements Uniform Affine Scalar Quantization — each individual weight is mapped to the nearest point on a learned uniform grid. This is fundamentally different from both Vector Quantization (VQ) and Finite Scalar Quantization (FSQ).

Vector Quantization (VQ)

  • Explicit codebook of K vectors
  • Nearest-neighbor lookup
  • One index per group of weights
  • Codebook collapse problem
  • Non-uniform spacing

EfficientQAT (This Codebase)

  • Implicit grid via affine transform
  • Round to nearest integer
  • One integer per individual weight
  • No collapse possible
  • Uniform spacing (learned scale)

Finite Scalar Quantization (FSQ)

  • Fixed quantization levels
  • No learned parameters
  • One integer per scalar
  • No auxiliary loss needed
  • Levels are hyperparameters

Straight-Through Estimator (STE)

The rounding function round(x) has zero derivative almost everywhere (it's piecewise constant). The STE pretends the function is the identity during backpropagation, allowing gradients to flow through the quantization step.

Forward vs. Backward Pass Through round_ste()

Implementation

def round_ste(x):
    # Forward: returns round(x)
    # Backward: gradient = 1 (identity)
    return (x.round() - x).detach() + x

The trick: (x.round() - x) computes the rounding residual. .detach() stops gradients through it. Adding back x gives the rounded value in forward, but identity gradient in backward.

Forward: f(x) = round(x)
Backward: ∂f/∂x ≈ 1

Two-Phase Training Pipeline

Phase 1: Block-AP

Block-wise Alternating Parameters

  • • Train one block at a time
  • • Optimizes: W, scale, zero_point
  • • Loss: MSE vs. FP block output
  • • LR: 1e-4 (quant), 1e-5 (weight)

Phase 2: E2E-QP

End-to-End Quantization Parameters

  • • Train entire model
  • • Optimizes: ONLY scale
  • • Loss: Cross-entropy (LM)
  • • LR: 1e-5 to 2e-5

Bit Packing: From Integers to INT32

After quantization, integer values are packed into 32-bit words for memory-efficient storage. For 4-bit quantization, 8 weights share one INT32. For 2-bit, 16 weights share one INT32.

Group-wise Quantization

Rather than using a single (scale, zero_point) pair for an entire weight matrix, EfficientQAT divides weights into groups (typically 64 or 128 consecutive values). Each group gets its own learned parameters, allowing the grid to adapt to local weight distributions.

Storage Breakdown (Real Quantization)

Per linear layer (out_features × in_features):
┌─────────────────────────────────────────────────────────┐
│ qweight: (in / (32/bits)) × out × 4 bytes (INT32)      │
│ scales:  (in / group_size) × out × 2 bytes (FP16)      │  ← trainable in E2E-QP
│ qzeros:  (in / group_size) × (out / (32/bits)) × 4B    │
└─────────────────────────────────────────────────────────┘

Example: 4096×4096 layer, 4-bit, group_size=128:
  qweight: (4096/8) × 4096 × 4 = 8 MB
  scales:  (4096/128) × 4096 × 2 = 0.25 MB
  qzeros:  (4096/128) × (4096/8) × 4 = 0.5 MB
  Total: 8.75 MB  (vs 32 MB in FP16 → 3.66× compression)

Algorithm: Complete Pipeline

Block-AP Algorithm (Phase 1)

Input: Full-precision model M, calibration data D, bits N, group_size g
Output: Quantized model M_q

1. Capture inputs to first transformer block using D
2. For each block i = 0, 1, ..., L-1:
   a. Clone block → Q_block (with QuantLinear layers)
   b. Compute FP output: Y_fp = Block_fp(X)
   c. Enable fake quantization on Q_block
   d. Initialize per-group (s, z) via Max-Min:
      s = (max(group) - min(group)) / (2^N - 1)
      z = round(-min(group) / s)
   e. For epoch = 1, ..., E:
      For each batch x in D:
        Y_q = Q_block(x)          // forward with STE
        loss = MSE(Y_fp, Y_q)     // reconstruction loss
        ∇s, ∇z, ∇W = backprop(loss)  // via STE
        s ← s - lr_q · ∇s        // update quantization params
        z ← z - lr_q · ∇z
        W ← W - lr_w · ∇W        // update weights
   f. Apply quantization in-place: W ← fake_quant(W)
   g. Pack into INT format (optional)
   h. Update block inputs: X ← Q_block(X)
3. Return quantized model M_q

E2E-QP Algorithm (Phase 2)

Input: Quantized model M_q from Block-AP, training data D
Output: Fine-tuned model M_q*

1. Load M_q (bit-packed weights, FP16 scales)
2. Dequantize: W_float = (W_int - z) · s  // for each layer
3. Freeze all parameters except scales
4. For each batch (x, y) in D:
   logits = M_q(x)                // full forward pass
   loss = CrossEntropy(logits, y) // language modeling loss
   ∇s = backprop(loss)            // simplified: ∂Ŵ/∂s = W_q - z
   s ← s - lr · ∇s               // update scales only
5. Return fine-tuned M_q*

Key insight: ∂Ŵ/∂s = W_int - z (no rounding noise)
This clean gradient allows stable end-to-end optimization.
